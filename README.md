 آواز میں درد مگر لہجے میں حوصلہ رکھیں:
باشہ کے لوگو… ذرا سوچو
کب تک ہم وعدوں پر یقین کرتے رہیں گے؟
نہ ہمارے اسکولوں میں سہولت ہے،
نہ سڑکیں ہیں، نہ بجلی پوری،
نہ بیمار کو وقت پر علاج ملتا ہے۔
الیکشن کے دن آتے ہیں،
مسکراہٹیں، وعدے، تصویریں…
اور پھر پانچ سال خاموشی۔
اب وقت آ گیا ہے کہ ہم جاگیں۔
ووٹ ہمارا حق ہے، ہماری طاقت ہے۔
اسے صرف وعدوں پر نہیں،
کارکردگی پر دیں۔
باشہ کو بدلنا ہے؟
تو آج سے فیصلہ بدلنا ہوگا۔
ووٹ وعدوں پر نہیں، کارکردگی پر دیں!
